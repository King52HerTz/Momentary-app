# 片刻 v0.2：陪伴与装订闭环

## 阶段目标

把当前可演示原型推进为可以连续使用的本地版本。用户能够定义不同的 AI 陪伴角色，在角色之间切换对话，并确保片刻、心情、对话、收藏与日记在应用重启后仍然保留。

## 用户价值

1. 一闪而过的想法可以立刻记录，也可以带进对话继续展开。
2. 不同情绪可以选择不同陪伴方式，不被单一语气限制。
3. AI 回应可以收藏或收录到当天，最后装订为日记。
4. 核心数据默认只保存在设备本地，为后续加密和云同步留下边界。

## 本阶段范围

### P0：本轮实现

- 内置三种陪伴角色：温柔倾听、故事陪伴、清晰复盘。
- 支持创建自定义角色，填写名称、角色说明和回应偏好。
- 聊天页支持切换角色，每个角色保留独立对话流。
- AI 原型回复根据角色风格产生差异化表达。
- 本地持久化片刻、心情、聊天、收藏、收录状态、日记、角色与当前选择。
- 日期改为读取设备当天日期，不再使用原型中的固定日期。
- 补充角色回复的单元测试与基础回归验证。

### P1：下一轮

- “开始日记 / 结束日记”会话状态机，采集中仅回复“收到”。
- 根据当天内容生成结构化日记、五项摘要和生活洞察。
- 日记内容可编辑，待办可勾选并延续到次日。
- 自定义角色支持编辑、归档和删除。

### P2：后续

- 接入可配置的大模型服务，密钥使用 Android Keystore 保护。
- 日记长图与摘录卡片导出，支持系统分享和保存到相册。
- 应用锁、本地数据库加密、备份恢复与可选云同步。
- 全文搜索、月度回顾与情绪趋势。

## 信息架构

- 今天：快速记录、心情、时间线、进入对话、整理今天。
- 日记：已装订日记与按月浏览。
- 回响：收藏的个人片刻和 AI 回应。
- 我的：陪伴角色、导出偏好、隐私与数据。

## 数据边界

- `MomentEntry`：当天片刻及来源。
- `ChatMessage`：消息、角色归属、收藏和收录状态。
- `AiPersona`：角色名称、说明、回应偏好和内置标识。
- `Journal`：装订后的日记快照。
- `MomentaryStore`：当前阶段的本地 JSON 持久化入口。

当数据量、搜索和迁移需求增长时，再将 `MomentaryStore` 替换为 Room；UI 和 ViewModel 不直接依赖 JSON 结构。

## 验收标准

1. 创建自定义角色后重启应用，角色仍然存在。
2. 切换角色后，只展示该角色的对话，并使用对应语气回复。
3. 收藏、收录、心情和日记在重启后保持不变。
4. 当天日期来自设备，装订日记不会重复创建。
5. `testDebugUnitTest`、`lintDebug` 和 `assembleDebug` 全部通过。

## 风险与约束

- 本阶段 AI 仍为离线规则原型，角色偏好用于差异化表达，不代表真实大模型能力。
- 不默认模仿在世作家的独特文风；自定义角色应描述希望获得的语气和陪伴方式。
- 当前 SharedPreferences 适合早期单用户数据，正式同步前需要迁移到带版本的数据库结构。
