# 片刻 UI 重设计规范

## 设计方向

参考“排版小动物”的轻量纸张感，以及现有原型中的柔黄和橄榄绿，形成“纸张编辑器 + 私人日记”的视觉语言。界面应安静、轻巧、有一点手作温度，但不能像儿童手账或复古模板。

## 核心原则

1. 内容优先：用户写下的话比装饰更醒目。
2. 低容器感：不用每一段都套厚重卡片，依靠留白、细线和纸色分组。
3. 克制用色：柔黄只标记当前选择和重要片刻，橄榄绿承担主要操作，雾蓝与灰粉仅作辅助。
4. 字体分工：界面与标题使用中文无衬线，日记正文和引用才使用衬线。
5. 轻质感：阴影接近零，边框 1dp，圆角 4–8dp；不使用大面积渐变和过度胶囊化。
6. 线稿交互：按钮优先使用统一线性图标，保证至少 48dp 点击区域。

## 设计令牌

- 纸张背景：`#FBFAF4`
- 抬升纸张：`#FFFDF8`
- 主文字：`#23241D`
- 次文字：`#74736A`
- 橄榄绿：`#596510`
- 柔黄：`#FFF0A3`
- 雾蓝：`#DCE9E8`
- 灰粉：`#F1DEDB`
- 分割线：`#DDD8C9`

间距使用 4dp 基础网格：4 / 8 / 12 / 16 / 24 / 32。

## 页面规则

- 首页首屏必须同时看到快速记录、心情入口和至少一条今日片刻。
- 主标题不超过 30sp；卡片内标题不超过 18sp。
- 同一屏仅保留一个高强调主操作。
- 列表项用稳定尺寸和细分割关系，不通过厚阴影制造层级。
- 选中状态必须同时使用颜色和图标/边框表达。

## 动效与可访问性

- 状态切换使用 150–220ms 的淡入或颜色变化，不做装饰性弹跳。
- 正文对比度达到 WCAG AA，次要文字不低于可读阈值。
- 图标按钮提供明确的 `contentDescription`，触控目标不小于 48dp。
- 字体放大时允许文本换行，不截断核心内容。
